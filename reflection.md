# Project Reflection

One important design decision I made in this project was to combine Amazon Bedrock AgentCore tools with a custom customer-support workflow rather than relying on a single model response. For example, I implemented the loyalty discount calculation as an AgentCore Code Interpreter tool. I chose this approach because the discount logic involves several business rules, including loyalty-point redemption, a 50% redemption cap, tier-based discounts, product-category earning rates, and remaining-point calculations. Executing this logic as Python code provides more reliable and reproducible arithmetic than asking the language model to calculate everything directly.

A major challenge I encountered was deploying the completed agent to AgentCore. The original Python Starter Toolkit CLI was outdated, so I migrated to the newer AgentCore CLI. I also encountered several environment and permission issues, including missing TypeScript and `uv` dependencies, CDK bootstrapping requirements, and IAM permissions for Memory, the Knowledge Base, and Code Interpreter. I resolved these issues step by step by validating the project, inspecting deployment logs, installing the required dependencies, bootstrapping the AWS environment, and granting the runtime role only the permissions required by each service. I then retested each capability after deployment.

For production use, security and observability would be especially important. The agent accesses customer information, order tools, long-term memory, and refund operations, so IAM permissions should follow the principle of least privilege. For example, the runtime role should only retrieve the specific knowledge base and memory resource required by the application instead of receiving broad AWS permissions. I would also enable centralized logging, tracing, alarms, and tool-level monitoring so failed requests, unusual refund activity, latency, and Code Interpreter usage can be detected quickly. Cost controls would also be useful for model calls, memory retrieval, browser sessions, and sandbox execution.
